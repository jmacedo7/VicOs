# VicOs

**VicOs — Your Business Operating System**

One company. One system. VicOs.

O VicOs é um SaaS multiempresa para centralizar contatos, contas, financeiro, equipe, sincronização e histórico operacional em um único ambiente.

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase / PostgreSQL
- Supabase Auth
- Vercel
- GitHub

## Marca
O nome oficial do produto é **VicOs**, com o **O em maiúsculo**.

## Autenticação
O projeto está preparado para Supabase Auth com e-mail e senha e a opção **Continuar com Google** via OAuth.

## Segurança
Os dados das empresas são isolados por `company_id` e protegidos por Row Level Security no Supabase.
