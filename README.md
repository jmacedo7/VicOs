# VICOS

**VICOS — Your Business Operating System.**

One company. One system. VICOS.

VICOS is a multi-tenant SaaS for centralized company operations, including contacts, accounts, finance, team management, synchronization and audit history.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase / PostgreSQL
- Supabase Auth
- Vercel

## Status

Project foundation in progress.
